# Linux for Beginners

Beginner-friendly Linux study notes, organized unit by unit. Each unit pairs written notes (Markdown) with a slide presentation (PPTX) — good for quick revision or classroom use.

## Units

| Unit | Topic | Notes | Slides |
|------|-------|-------|--------|
| 1 | Linux Basics | `Chapter-1 Linux Basics.md` | `Linux_Basics.pptx` |
| 2 | Text Manipulation | `chapter-2 text manipulation.md` | `Text_Manipulation_for_Beginners_Presentation.pptx` |
| 3 | Analyzing and Managing Networks | `Chapter-3-Analyzing-and-Managing-Networks.md` | `networking-concepts-study-notes.pptx` |
| 4 | Adding and Removing Software (APT Package Management) | `Unit-4-adding and removing software.md` | `Professional_APT_Package_Management_Presentation.pptx` |

## How to use

Open any `.md` file in a Markdown viewer (or right here on GitHub) to read the notes, and the matching `.pptx` for the presentation version.
